# DevPulse – avance 35%

Instalación:
    npm create vite@latest devpulse -- --template react-ts
    cd devpulse && npm i framer-motion lucide-react
    npm i -D tailwindcss @tailwindcss/vite   # Tailwind v4: añade el plugin en vite.config.ts y `@import "tailwindcss";` en src/index.css

Copia la carpeta `src/` de este entregable sobre la de Vite y ejecuta `npm run dev`.
Para empaquetar como app de escritorio: añade Electron o Tauri más adelante.
